**Target Date:** April 18, 2026

## Exam Overview
- 50 questions, 2 hours
- Multiple choice + multiple select
- Passing score: ~70%
- Topics: setting up a cloud solution environment, planning + configuring, deploying + implementing, ensuring successful operation, configuring access + security

---

## Week 1 (Mar 8–14) — Foundations
**Goal:** Get comfortable with GCP console, core services, and the CLI

- [ ] Set up Google Cloud Skills Boost free account (cloud.google.com/training)
- [ ] Complete "Google Cloud Fundamentals: Core Infrastructure" (free with Skills Boost trial)
- [ ] Review: Projects, billing, IAM basics, gcloud CLI
- [ ] Hands-on: Create a project, spin up a VM, SSH in, tear it down
- [ ] Read: [ACE exam guide](https://cloud.google.com/certification/guides/cloud-engineer)

**Daily time:** 45–60 min

---

## Week 2 (Mar 15–21) — Compute + Storage
**Goal:** Know Compute Engine, GKE, Cloud Run, and storage options cold

- [ ] Compute Engine: instance types, managed instance groups, autoscaling, load balancing
- [ ] GKE: cluster creation, node pools, kubectl basics, workloads
- [ ] Cloud Run: deploying containers, scaling, traffic splitting
- [ ] Cloud Storage: buckets, object lifecycle, access control, signed URLs
- [ ] Cloud SQL + Firestore basics
- [ ] Hands-on: Deploy a containerized app to Cloud Run via Terraform (your existing lab)

**Daily time:** 45–60 min

---

## Week 3 (Mar 22–28) — Networking + Security
**Goal:** VPCs, firewall rules, IAM, and identity

- [ ] VPC: subnets, routes, peering, shared VPC
- [ ] Firewall rules, Cloud Armor basics
- [ ] IAM: roles, service accounts, workload identity, policy bindings
- [ ] Secret Manager, Cloud KMS basics
- [ ] Cloud DNS, Cloud NAT, Private Google Access
- [ ] Hands-on: Build a VPC with private subnet + Cloud NAT

**Daily time:** 45–60 min

---

## Week 4 (Mar 29–Apr 4) — Operations + Monitoring
**Goal:** Cloud Monitoring, Logging, deployment tooling

- [ ] Cloud Monitoring: dashboards, alerting policies, uptime checks
- [ ] Cloud Logging: log sinks, log-based metrics, audit logs
- [ ] Cloud Trace, Cloud Profiler basics
- [ ] Deployment Manager vs Terraform (know both exist, know Terraform better)
- [ ] Cloud Build, Artifact Registry basics
- [ ] Hands-on: Set up alerting on a Cloud Run service

**Daily time:** 45–60 min

---

## Week 5 (Apr 5–11) — Practice Exams + Gap Fill
**Goal:** Identify weak spots and drill them

- [ ] Take a full practice exam (Udemy — Jon Bonso's GCP ACE practice tests, ~$15 on sale)
- [ ] Score it, note every wrong answer, look up the concept
- [ ] Take a second practice exam
- [ ] Focus extra time on whatever you're missing (usually: networking details, billing/quota management, GKE specifics)
- [ ] Review official ACE sample questions (free on Google's site)

**Daily time:** 60–90 min

---

## Week 6 (Apr 12–18) — Final Review + Test Day
**Goal:** Confidence, not cramming

- [ ] Apr 12–15: Light review of weak areas only, no new topics
- [ ] Apr 16: One more practice exam, review wrong answers
- [ ] Apr 17: REST. Seriously. Light review of your notes only.
- [ ] Apr 18: **EXAM DAY** 🎯

**Test day tips:**
- Read every question twice
- Eliminate obviously wrong answers first
- "Most secure / least privilege" is almost always right for IAM questions
- "Managed service over self-managed" is usually the GCP-preferred answer
