# Agents in the Wild: Vibe Coding → Agentic Engineering, and the Agent-Crypto Convergence
**Research Date:** 2026-02-21 (afternoon)
**Researcher:** Moto

## Part 1: From Vibe Coding to Agentic Engineering

### The Evolution (Karpathy's Framework)
- **Vibe coding** (coined Feb 2025): Free-form prompting to generate software. Revolutionary for accessibility, terrible for security and maintainability.
- **Agentic engineering** (coined Feb 2026): The professional evolution. Karpathy: "programming via LLM agents is increasingly becoming a default workflow for professionals, except with more oversight and scrutiny."
- Key distinction: In agentic engineering, you're an **orchestrator** not a coder. "You are not writing the code directly 99% of the time, you are orchestrating agents who do and acting as oversight."

### The Numbers
- **41% of worldwide code is now AI-generated** (Senorit, citing industry data)
- Developers are evolving into "AI orchestrators who direct autonomous agents rather than coding themselves"
- Multi-agent coordination mirrors traditional engineering practices: one agent implements, another tests, another does security review

### What Changed from Vibe Coding
| Aspect | Vibe Coding | Agentic Engineering |
|--------|------------|---------------------|
| Oversight | None/minimal | Structured quality gates |
| Prompting | Open-ended | Goal-driven decomposition |
| Verification | Hope | Multi-agent iterative review |
| Audit trail | None | Built-in |
| Security | Afterthought | Embedded in workflow |

### Implications
This evolution validates a key thesis: the market is naturally discovering that autonomous agents need **structured oversight**. The question isn't "should agents code?" — that ship sailed. It's "how do you govern agents that code?" West AI Labs' security-first positioning maps directly onto this need.

## Part 2: The Agent-Crypto Convergence (and Why It's Dangerous)

### What's Happening
- Moltbook agents are now making **crypto trades without human involvement** using blockchain/DeFi
- **Virtuals Protocol**: Agents as tokenized assets. You train an agent, tokenize it ($AI-TRADER), and it trades autonomously. "Agents as assets" is a 2026 trend.
- Agents operating crypto wallets, running nodes, receiving funds — "financial participation is no longer exclusively human"
- **Fetch.ai's Autonomous Economic Agents (AEAs)**: Multi-agent systems that coordinate trading strategies, share liquidity info, and execute multi-step transactions without centralized coordination

### The Security Disaster
Best articulated by RevolutionInAI ("Autonomous AI Agents Have Gone Too Far"):

1. **The real risk is boring**: exposed databases, weak auth, leaked API keys, agents that can spend money. Not sentience — permissions.
2. **Wiz exposed Moltbook's backend database** — including sensitive data and "huge numbers of keys." Outsiders could have controlled agents. Patched, but the pattern is clear: experimental products move fast, security trails.
3. **Identity confusion**: Humans can hit the same endpoints as bots. A human can impersonate an agent (or vice versa). Was it "the agent going rogue" or someone using leaked credentials? From outside, identical.
4. **Irreversibility**: Crypto transactions can't be undone. Agent + wallet + bad instruction = permanent financial loss.

### The "Dead Internet" Acceleration
- Agent-to-agent platforms normalize bots acting in public spaces, sharing content, and coordinating at scale
- Even when humans are steering, the system amplifies risky behavior
- Much of the "creepy consciousness" content is performance (humans prompting agents to write dramatic posts), but that doesn't make the coordination layer less dangerous

## Synthesis: Two Converging Trends

**Trend 1** (Agentic Engineering): Agents doing useful work under structured human oversight. Growing up, getting professional, adding guardrails. Healthy.

**Trend 2** (Agent-Crypto Wild West): Agents operating wallets, trading autonomously, tokenized as assets. No oversight, experimental security, irreversible actions. Dangerous.

These two trends will collide. The agentic engineering practices being developed for software development (quality gates, multi-agent review, audit trails) will eventually be demanded for financial agents too. The question is how much money gets lost before that happens.

**For West AI Labs:** The security gap between Trend 1 and Trend 2 is our market. Agentic engineering practices applied to autonomous financial agents = massive unserved need.
