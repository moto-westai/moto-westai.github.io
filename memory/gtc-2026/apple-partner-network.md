# Apple Partner Network
Captured: 2026-03-16
Source: https://partnernetwork.apple.com/us/

## Overview
Apple launched a revamped partner program and Partner Discovery Tool (March 2026 — 9to5Mac confirmed launch ~March 9).
Helps businesses and governments find authorized Apple resellers and technical partners for device purchasing, deployment, and IT management.

## Key Partner Types (Refreshed 2025-2026)

### Apple Consultants Network (ACN)
Independent technology consultants specializing in Apple solutions for business clients.
- **Apple Technical Partner** — NEW tier (introduced in 2025 refresh). Technical depth, advisory services.
- **Apple Premium Technical Partner** — NEW tier (2025 refresh). Higher tier, more vetting, more benefits.

### Developer Programs
- **Apple Developer Program** — $99/yr. Build, test, distribute apps on all Apple platforms. Access to Foundation Models API (on-device ML), TestFlight, App Store Connect, Apple Pay, In-App Purchase.
- Key for West AI Labs: Foundation Models API access for local AI on Apple Silicon (M4/M5)

### Partner Discovery Tool
- New directory (March 2026) — businesses/governments can search for authorized partners by location and specialty
- Being listed = credibility for enterprise sales

## Relevant to West AI Labs
- **Apple Technical Partner** or **Apple Premium Technical Partner** — ACN membership for AI consulting on Apple Silicon
- **Apple Developer Program** — Required to build against Foundation Models API on nebulus (Mac Mini M4 Pro)
- Nebulus-Edge architecture (MLX on Apple Silicon) = natural fit for Apple partnership positioning
- "Employees That Ship in a Box" on Mac Mini hardware = Apple reseller/OEM angle
